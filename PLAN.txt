!USING AN MC ACCESS TABLE FOR ALL THE SCHOOL DATA!

!THE TABLE IS CALLED "SCHOOL_DATA"

!THE FIELDS IN THE TABLE ARE AS FOLLOWS:
!SCHOOL_ID (PRIMARY KEY)
!STUDENT/TEACHER NAME
!PHONE NUMBER
!EGN (WHICH SHOULD LOOK REAL BUT ISNT)
!ROLE (IF TEACHER) FOR EXAMPLE HISTORY (IF STUDENT) THE CLASS THEY ARE IN FOR EXAMPLE 10B
!EMAIL

UPON SIGNING UP TO THE SYSTEM THE USER IS PROMPTED TO USE THE SAME EMAIL AS THE ELECTONIC GRADING SYSTEM NO MATTER WHICH IT IS (SAME AS WE MOCK THE EXPORT FROM WITH THE ACCESS TABLE)

!WHEN THE USER LOGS IN THE SYSTEM CHECKS IF THE EMAIL EXISTS IN THE TABLE
!IF IT DOESN'T IT PROMPTS THEM TO CONTACT THE ADMINISTRATOR
!IF IT DOES IT CHECKS IF THE ROLE FIELD IS A TEACHER OR A STUDENT
!IF IT IS A TEACHER IT ALLOWS THEM TO ACCESS THE TEACHER PORTAL
!IF IT IS A STUDENT IT ALLOWS THEM TO ACCESS THE STUDENT PORTAL

!TEACHER PORTAL
